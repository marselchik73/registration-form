# registration-form
Форма регистрации с валидацией логина (буквы, 5–15 символов) и пароля (мин. 5 символов). Кнопка меняет цвет при наведении только когда оба поля валидны, иначе ошибки подсвечиваются.
# Форма регистрации (тестовый стенд)

## Функциональность

### Поле «Логин»
- Допустимые символы: только русские и английские буквы (включая `ёЁ`).
- Длина: от 5 до 15 символов.
- При невалидном значении:
  - красная рамка вокруг поля,
  - под полем появляется сообщение об ошибке.

### Поле «Пароль»
- Минимальная длина: 5 символов (любые символы разрешены).
- При невалидном значении:
  - красная рамка,
  - сообщение об ошибке под полем.

### Кнопка «Зарегистрироваться»
- **По умолчанию** (пока хотя бы одно поле невалидно) – серая, **цвет при наведении НЕ меняется**.
- **Когда оба поля валидны** – кнопка становится синей, **при наведении меняет цвет** на более тёмный синий + появляется тень.
- При клике на валидную форму – выводится `alert` с сообщением об успехе.
- При клике на невалидную форму – ошибки уже подсвечены, фокус переходит на первое некорректное поле.

## Поведение, важное для тестирования

| Сценарий | Ожидаемый результат |
|----------|----------------------|
| Логин содержит цифру (например, `user123`) | Красная рамка + ошибка «Логин должен состоять только из букв...» |
| Логин из 4 букв (`user`) | Ошибка о длине (нужно 5–15) |
| Логин из 16 букв | Ошибка о длине |
| Логин из 5 русских букв (`привет`) | Валидно, кнопка становится синей |
| Пароль из 4 символов | Красная рамка + ошибка «не менее 5 символов» |
| Пароль из 5 звёздочек (`*****`) | Валидно |
| Оба поля пустые | Кнопка серая, ховер не работает |
| Ввести валидный логин + валидный пароль → навести курсор на кнопку | Цвет кнопки меняется (синий → тёмно-синий) |
| После валидных данных стереть 1 символ из пароля | Кнопка сразу становится серой, ховер пропадает |
